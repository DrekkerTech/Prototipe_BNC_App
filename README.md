# Prototipo BNC App

APK Android del prototipo móvil de experiencia bancaria desarrollado por DrekkerTech.

> Este es un prototipo independiente de interfaz y flujo. Usa datos simulados, no se conecta a sistemas bancarios reales y no representa una aplicación oficial ni aprobada por BNC.

## Instalación

1. Descarga el APK desde la tabla anterior en un dispositivo Android.
2. Permite la instalación desde la aplicación que realizó la descarga, si Android lo solicita.
3. Abre el archivo y confirma la instalación.

Requiere Android 7.0 o posterior (API 24).

## Alcance de la demo

- Navegación de cuentas, tarjetas, pagos, Pago Móvil, divisas y asistente de voz.
- Flujos y movimientos demostrativos con datos ficticios.
- Sin servicios financieros, autenticación bancaria ni procesamiento de pagos reales.

## Nota de compilación

El APK fue compilado localmente como `release` y firmado con una clave de depuración para pruebas e instalación interna. No está firmado para Google Play ni debe usarse como artefacto de producción.
